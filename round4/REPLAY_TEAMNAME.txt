AGENT_HARNESS: Claude Code v2.1.280
ENV_SETUP: Python 3 only, standard library, no pip install and no requirements.txt (tested on Python 3.14.7; on Windows use "python" wherever "python3" is missing). Install Claude Code (https://docs.claude.com/en/docs/claude-code) and sign in; its WebSearch tool must be available for the off-site corroboration step. Needs outbound HTTPS. The engine is the Round 3 package submission.zip, SHA-256 1d5e0f3e4dd12a8c12e205b4723124b4d441cdbf3f76605a2befde9114ec33b1, also at the root of https://github.com/aithal007/ai_readness. On Windows, set PYTHONUTF8=1 before step 4 so console output from the scripts never hits an encoding error (bash: export PYTHONUTF8=1, PowerShell: $env:PYTHONUTF8="1").
TEST_STEPS:
 1. In an empty directory that contains submission.zip, unpack it. The same command works in bash, PowerShell and cmd.
      python3 -m zipfile -e submission.zip r3
 2. Install the package's skills, unchanged, where Claude Code discovers project skills, and create the output folder.
      python3 -c "import shutil, os; shutil.copytree('r3/brand-ai-readiness-audit/skills', 'demo/.claude/skills'); os.makedirs('demo/audit_out')"
 3. Enter the workspace.
      cd demo
 4. Start the harness pointed at the entrypoint skill's workspace. Allowing Skill is required: without it Claude Code will not load the audit-orchestrator skill. Bash is allowed because the skill runs its Python scripts; run this in the throwaway demo directory only.
      claude --model claude-sonnet-5 --allowedTools Skill Bash Read Write Glob Grep WebSearch
 5. Give the agent this prompt, verbatim. To audit a site of your own choosing, change only the URL.
      Use the audit-orchestrator skill to audit https://www.sqlite.org/ for AI discoverability and on-site engagement. Use today's real date. Write every output file into ./audit_out/, ending with audit_out/audit_report.json and audit_out/audit_report.md. Then summarise the critical and high findings and the remediation roadmap.
 6. The agent calls the Skill tool on audit-orchestrator (the marketplace entrypoint). The skill crawls the site once into audit_out/evidence.json and runs six analyzers over that snapshot into audit_out/raw_findings.json. The agent then runs the two judgement checks the skill specifies (off-site corroboration by web search, homepage orientation), runs the evidence critic into audit_out/adjudicated.json, reviews what survives, and finalizes. The report lands in audit_out/audit_report.json (machine-readable) and audit_out/audit_report.md (readable). Each finding carries id, title, severity, evidence, suggested_action, plus a stable code, a confidence and an effort. The .md report has a Remediation roadmap section that sorts fixes into Do now, Next and Later by impact against effort (an empty bucket is omitted), then every finding in full, then a section listing the findings the critic suppressed and why. The agent's final chat message summarises critical and high findings and the roadmap. Wall-clock time was 2 to 7 minutes across our runs.
 7. Expected substance for https://www.sqlite.org/, stable across three independent runs on this harness and model. Wording, finding count (12 to 20) and readiness score (90 to 96) vary between runs. Zero critical and zero high findings. GPTBot and ClaudeBot receive HTTP 403 while a browser user agent receives 200; the scripts propose this as a critical network-layer block, and the agent reports it as a training-crawler refusal at low or medium, never critical, because training crawlers do not affect citation. No usable XML sitemap (medium): /sitemap.xml returns 404 and robots.txt has no Sitemap line. No structured data on any sampled page (medium or low). Homepage has no H1, its headings are all H3 (medium or low). No lang attribute on the html element (low). Most pages have no meta description (low). Every one of these can be checked with curl.
 8. Headless variant of steps 4 and 5, used for our third verification run (same model, same allowed tools, same prompt):
      claude -p "Use the audit-orchestrator skill to audit https://www.sqlite.org/ for AI discoverability and on-site engagement. Use today's real date.
